# 🌦️ Smart Weather Monitoring Station Using NodeMCU ESP8266 and KiwisIoT

## Project Description

The Smart Weather Monitoring Station is an IoT-based project designed to monitor environmental conditions such as temperature and humidity in real time.

This project uses a **NodeMCU ESP8266**, a **DHT11 temperature and humidity sensor**, and the **KiwisIoT platform** to collect and monitor weather information.

The DHT11 sensor continuously measures the surrounding temperature and humidity. The NodeMCU ESP8266 collects the sensor readings and connects to the internet through Wi-Fi. The collected information can then be viewed on the KiwisIoT dashboard.

This project makes weather monitoring simple, easy, and accessible from anywhere with an internet connection.

## Main Features

- Real-time temperature monitoring.
- Real-time humidity monitoring.
- Wi-Fi connectivity using NodeMCU ESP8266.
- Live sensor data monitoring through KiwisIoT.
- Simple and beginner-friendly IoT project.

## Components Used

1. NodeMCU ESP8266
2. DHT11 Temperature and Humidity Sensor
3. Jumper Wires
4. USB Cable
